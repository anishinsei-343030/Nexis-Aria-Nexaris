# Data Science Skills

## Purpose
Enable data analysis and visualization:
- **Jupyter notebooks**: Live kernel interaction.
- **Data exploration**: Pandas, NumPy, SQL.
- **Visualization**: Matplotlib, Seaborn, Plotly.

## Subskills
| Name | Purpose |
|------|---------|
| jupyter-live-kernel | Iterative Python via live Jupyter kernel. |

## Usage
Load this skill when:
- Analyzing datasets.
- Generating charts or reports.
- Running Jupyter notebooks.

## Pitfalls
- Jupyter kernels may crash on large datasets.
- Visualizations may require tuning for readability.
