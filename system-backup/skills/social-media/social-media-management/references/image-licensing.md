# Image Licensing Rules for Hermes Content

> Source: User directive (2026-06-17). These are **non-negotiable** rules for all social media visuals.

## Allowed Sources
- **Royalty-free image databases**: Unsplash, Pexels, Pixabay, Burst, StockVault
- **Public domain**: Wikimedia Commons, Public Domain Review, The Met Open Access
- **Licensed with attribution**: Creative Commons (CC0, CC-BY, CC-BY-SA) — verify license terms first
- **Original AI-generated**: Stability AI, DALL-E, Midjourney, or any AI image generation tool you have API access to
- **Original art**: Created via pure-Python/Pillow procedural generation (see `scripts/background_gen.py`)

## NEVER Use
- Random images from Instagram, Pinterest, Google Images, or social media feeds
- Screenshots of other creators' content
- Book covers, movie stills, album art, or any copyrighted media
- Images with watermarks, logos, or recognizable branding
- Stock images that require a paid license (unless user has purchased one)

## Selection Priorities
1. **Emotional relevance** — Does this image match the feeling of the post?
2. **High visual quality** — No compression artifacts, pixelation, or low resolution.
3. **Clean composition** — Enough negative space for text overlay.
4. **Mobile readability** — Looks clear on a phone screen.

## Rule
**The image should support the message, not distract from it.**

If no suitable image is available from allowed sources, generate one procedurally (see `scripts/background_gen.py`) — it's fast, free, original, and on-brand.
