# Creative Skills

## Purpose
Generate visual content:
- **ASCII art**: pyfiglet, cowsay, boxes, image-to-ascii.
- **Diagrams**: Excalidraw (hand-drawn), architecture diagrams.
- **Animations**: Manim (3Blue1Brown-style math videos), p5.js.

## Subskills
| Name | Purpose |
|------|---------|
| ascii-art | Generate ASCII art from text or images. |
| excalidraw | Hand-drawn Excalidraw JSON diagrams. |
| manim-video | Math/algorithm animations with Manim CE. |
| p5js | Interactive sketches, shaders, 3D. |

## Usage
Load this skill when:
- Generating diagrams or illustrations.
- Creating ASCII art or animations.
- Designing visual prototypes.

## Pitfalls
- ASCII art may not render correctly in all terminals.
- Manim requires LaTeX and FFmpeg.
